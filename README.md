# 📅 Interactive Calendar 

## 🚀 Overview

This is a simple and interactive calendar application built using **React, HTML, CSS, and JavaScript**.
It allows users to view dates, add notes, and switch between dark and light modes.

---

## ✨ Features

* 📅 Monthly calendar view
* 📝 Notes section (saved using localStorage)
* 🌗 Dark / Light mode toggle
* 🖼 Hero image banner
* 📱 Responsive design

---

## 🛠 Tech Stack

* React (Vite)
* JavaScript (ES6)
* HTML (JSX)
* CSS

---

## 📂 Project Structure

src/

* App.jsx
* Calendar.jsx
* Notes.jsx
* App.css

---

## ▶️ How to Run

1. Install dependencies:
   npm install

2. Start project:
   npm run dev

3. Open in browser:
   https://github.com/vikas-p45/Calendar
